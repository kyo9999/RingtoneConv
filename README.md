RingtoneConv	Custom Ringtone & Alarm Tone

RingtoneConv: A simple ringtone maker that works without third-party software. Record audio, import audio files, extract audio from videos, and trim clips to customise system ringtones and alarm tones. An all-in-one ringtone editor.

● Audio Trimming · Ringtone Creation
- Visually trim audio on the timeline and quickly capture clips with preview playback
- Export formats: M4A, WAV; M4A is recommended for system ringtones
- Audio shorter than 30 seconds can be directly set as incoming call ringtones or alarm tones via the share panel
- Support renaming, deleting and sharing media files
> Note: For batch conversion, batch extract and multi-audio merging, search for AudioConv in the app store

● Recording · Audio Import · Audio Extraction from Video
- Built-in recorder to capture songs or your own voice
- Supported import audio formats: MP3, M4A, WAV, FLAC, AAC, AIFF, CAF
- Extract audio from videos; import media from the gallery or Files app
- Reuse existing media from the library directly

● Media Library Management
- Media tagged as [Original Files] or [Ringtones], one-click filter
- Support search, refresh and batch operations for media
- Files are saved permanently and will not be cleared automatically

● Lightweight & Secure · Easy to Use
- Tab layout: Create, Library, More, clear structure
- Real-time audio preview, play, pause, quick jump to start and end
- Small installation package, low resource usage, built on native system frameworks
- Local offline processing, no file uploads, protecting your privacy
- Illustrated guides and video tutorials available, including instructions for setting ringtones and removing system ringtones

RingtoneConv	自定义铃声与闹钟声

RingtoneConv：简易铃声制作工具，不依赖第三方软件实现。通过录音、音频导入、视频提取音频、裁剪，自定义系统铃声与闹铃声，一站式铃声编辑工具。

● 音频剪辑 · 铃声制作
- 时间轴可视化裁剪音频，快速截取片段，支持预览试听
- 导出格式：M4A、WAV；M4A推荐用于系统铃声
- 30秒以内音频，通过分享面板可直接设置为来电铃声、闹钟铃声
- 支持素材重命名、删除、分享管理
> 备注：如需批量转换、批量提取、多音频合成，应用商店搜索 AudioConv

● 录音 · 音频导入 · 视频提取音频
- 支持录音，录制歌曲或是自己的声音
- 可导入音频：MP3、M4A、WAV、FLAC、AAC、AIFF、CAF
- 从视频提取音频，支持相册、文件App导入素材
- 可直接选用资源库内已有素材复用

● 资源库素材管理
- 素材标记【原始文件】【铃声】，一键筛选
- 支持搜索、刷新、批量操作素材
- 文件永久保存，不会自动清除

● 轻量安全 · 简单易用
- 分页标签：创建、资源库、更多，结构清晰
- 音频实时预览，播放、暂停、快速跳转首尾
- 安装包小巧，资源占用低，依托系统原生框架
- 本地离线处理，不上传文件，保障隐私安全
- 配套图文+视频教程，包含铃声设置以及系统铃声删除指引
